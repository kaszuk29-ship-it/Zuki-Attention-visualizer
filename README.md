# Zuki Attention Visualizer

An interactive AI project that helps visualize how **attention mechanisms** work in a text-processing system.

## About the Project

**Zuki Attention Visualizer** is designed to make the concept of attention in AI easier to understand through visualization.

The project processes text, converts it into meaningful representations, and demonstrates how different words can receive different levels of attention while processing a sentence.

## Key Features

* Text input and processing
* Text embedding
* Attention calculation and visualization
* OCR-based text extraction
* Interactive user interface
* Easy-to-understand visualization of attention mechanisms

## Technologies Used

* **Python**
* **Streamlit**
* **NumPy**
* **OCR**
* **Attention Mechanism**
* **Text Embeddings**

## How It Works

The basic workflow of the project is:

```text
User Input
    ↓
Text / Image
    ↓

    ↓
Text Processing
    ↓
Embedding
    ↓
Attention Calculation
    ↓
Attention Visualization
    ↓
User Output
```

## Installation

### 1. Clone the repository

```bash
git clone https://github.com/kaszuk29-ship-it/Zuki-Attention-visualizer.git
```

### 2. Open the project folder

```bash
cd Zuki-Attention-visualizer
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```

The application will open in your browser.

## Purpose

The main purpose of this project is to provide a simple and visual way to understand the **attention mechanism used in modern AI and Natural Language Processing (NLP)**.

It can be useful for students and beginners who want to understand how AI models determine which parts of an input are important during processing.
